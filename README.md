# Data Cleaning and Sales Analysis Using Power BI

## Thiranex Internship – Task 4

### Project Overview

This project focuses on data cleaning, preprocessing, transformation, and sales analysis using Microsoft Power BI Desktop. The objective is to improve dataset quality by identifying inconsistencies, handling missing values, removing duplicate records, and preparing structured data for meaningful business analysis.

### Objectives

- Identify and remove duplicate records.
- Handle missing and null values.
- Correct inconsistent data types.
- Clean and standardize text fields.
- Identify and resolve data errors.
- Develop an interactive sales analysis dashboard.

### Tools and Technologies

- **Microsoft Power BI Desktop** – Data visualization and reporting
- **Power Query Editor** – Data cleaning and transformation
- **DAX** – Data aggregation and calculations
- **CSV Dataset** – Source data for analysis

### Dataset Description

The project uses a Superstore sales dataset containing information about customer orders, products, sales, profit, quantity, and geographical regions.

Key attributes include:

- Order ID and Row ID
- Order Date and Ship Date
- Customer Name and Segment
- Region and City
- Category and Sub-Category
- Sales, Profit, and Quantity

### Implementation

**1. Data Import**

Imported the dataset into Power BI Desktop and opened Power Query Editor for preprocessing.

**2. Data Quality Assessment**

Used Column Quality, Column Distribution, and Column Profile to inspect the dataset and identify missing values, errors, and inconsistencies.

**3. Duplicate Removal**

Removed duplicate records using the appropriate unique identifier to improve data accuracy.

**4. Missing Value Handling**

Identified null and empty values and applied suitable cleaning techniques based on the data type.

**5. Data Type Transformation**

Converted date, numerical, and text columns into appropriate formats.

**6. Text Standardization**

Applied Trim, Clean, and capitalization transformations to improve consistency across categorical fields.

**7. Data Validation**

Reviewed transformed columns to identify and resolve remaining data quality issues.

**8. Dashboard Development**

Created an interactive dashboard containing:

- Total Records
- Total Sales
- Total Profit
- Region-wise Sales Analysis
- Category-wise Sales Distribution
- Segment Slicer

### Project Outcomes

- Improved dataset consistency and usability.
- Prepared structured data for business intelligence reporting.
- Developed practical experience in Power Query transformations.
- Created interactive visualizations for exploring sales performance.
- Strengthened data preprocessing and analytical skills.

### How to Run

1. Download the project files from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` project file.
4. Update the dataset source path if required.
5. Click **Refresh** to load the data.
6. Explore the dashboard and its interactive visualizations.

### Conclusion

This task demonstrates the importance of data cleaning as a fundamental step in business intelligence. By applying Power Query transformations and developing an interactive dashboard, the project provides a structured approach to preparing and analyzing sales data.
